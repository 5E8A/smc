# Mods

The Mods tab provides a visual Kanban-style board for managing the mod list. Mods are organized into category columns defined in `@scripts/mod-list.json` and can be dragged between them.

## The Board

The board renders one column per mod category. Columns are not hardcoded; they are defined in `@scripts/mod-list.json` (single source of truth: `[{ key, slugs[] }]`), so the grid is dynamic and columns can be added or renamed by editing that file.

The current columns are:

| Column          | Description                   |
| --------------- | ----------------------------- |
| **Performance** | Performance-focused mods      |
| **Optifine**    | OptiFine-feature replacements |
| **QoL**         | Quality-of-life mods          |
| **Utility**     | Utility tools and helpers     |

Each column contains mod cards showing:

- Mod name
- Modrinth slug/ID
- Brief description (when available)

## Adding Mods

To add a new mod:

1. Click the **+** button at the top of a column
2. Enter a **Modrinth slug or full URL** in the input field
3. The board performs a live search against the Modrinth API
4. Select a result to add the mod to that column

The mod card appears immediately in the column. You can drag it to a different category if needed.

## Drag and Drop

Mods can be moved between columns by dragging their cards. This changes the mod's category assignment. The board re-renders immediately, changes are local until you save.

## Editing Mods

Click a mod card to expand its details. From there you can:

- Edit the mod's display name
- Change the description
- Remove the mod from the list

## Saving

When you make changes to the mod board:

1. Changes are stored locally in `@scripts/mod-list.json`
2. To apply changes to the live site, run **sync-mods** from the runner console

The sync-mods script fetches updated mod metadata from Modrinth and regenerates the mod data used by the site.

## File Mapping

| What                 | Where                            |
| -------------------- | -------------------------------- |
| Mod list definitions | `@scripts/mod-list.json`         |
| Synced mod data      | Generated by `npm run sync-mods` |
